# 产品原则

用户是高铁、隧道或弱 Wi-Fi 场景下使用 Claude Code/Codex 的本地开发者。产品保住已经准备好的本地工作与事实记录，网络恢复后再协同评估。

所有可观察状态必须可解释：连通不等于 API 授权成功；模型预估不等于网络保证；任务结果未知不等于失败；提示恢复不等于自动续接成功。

原始稿保存在 docs/source-design.md。安全边界修订集中在 docs/sdd-review.md，必须在产品实现前审阅。完整目标不因最小闭环而删除，未验收项显式保留。

不交付前端，不引入 React。文档中文，软件标识和 CLI 英文。推荐 MIT，由项目按该建议提供 LICENSE；第三方不复制代码。
