# 需求：离线执行与恢复

状态：完整审阅稿；任意命令可回滚的原始表述被限定为受管动作能力，待审阅。

## 项目描述
让预生成、已授权的本地步骤在断网时继续，并留下可核对、可恢复的事实。本规格不保证任意进程是安全的，也不拥有云端评估。

## 1. 权限与执行边界
用户故事：作为工作区所有者，我希望模型计划不能自行取得危险操作权限。

- 1.1 When 一个动作准备执行，the Yunyi shall 根据本地规则再次校验实际可执行程序、参数、工作目录和声明的写入范围，拒绝未批准的程序或参数组合。
- 1.2 If 动作包含 shell 管道、重定向、解释器执行字符串、越界路径或危险回滚，the Yunyi shall 默认拒绝，并返回可读原因；仅命令名称匹配不能构成许可。
- 1.3 When 中高风险动作需要授权，the Yunyi shall 暂停并给本地用户展示精确动作及副作用；模型或 MCP 调用不能自行批准。
- 1.4 If 无法获得工作区独占执行权或暂停交接未确认，the Yunyi shall 不启动会写文件的离线步骤，并保持待执行状态。
- 1.5 The Yunyi shall 将普通外部命令标注为本地信任执行而非沙箱执行，并在授权界面展示其回滚能力。

## 2. 依赖与步骤调度
用户故事：作为用户，我希望离线执行按依赖顺序推进且不会重复产生副作用。

- 2.1 While 离线执行启用，the Yunyi shall 串行选择所有前置任务成功的待执行任务，失败依赖的后续任务保持 blocked。
- 2.2 When 每一步开始前，the Yunyi shall 已持久化领取凭证、动作审批依据和前检查点；写入失败不得执行动作。
- 2.3 When 步骤完成，the Yunyi shall 保存退出码、耗时、受限输出摘要、文件变化和后检查点，之后才推进到下一步。
- 2.4 If 步骤失败，the Yunyi shall 仅对明确声明幂等且获准重试的步骤按有限次数重试；未知结果与非幂等动作不得自动重试。
- 2.5 When 用户中止或收到恢复事件，the Yunyi shall 立即停止领取新步骤，并让当前步骤进入有界收尾或明确的超时处理。

## 3. 子进程与资源
用户故事：作为用户，我希望超时和退出后不留下后台工作进程。

- 3.1 When 启动外部命令，the Yunyi shall 使用参数列表直接启动，在 Windows 上把受管进程及其后代纳入生命周期管理，并持续读取输出避免管道阻塞。
- 3.2 If 达到步骤超时或用户强制取消，the Yunyi shall 终止受管进程树、确认清理结果并记录 timed_out 或 cancelled；无法确认的副作用状态应进入 needs_reconciliation。
- 3.3 If 进程控制能力不可用、进程标识复用或权限不足，the Yunyi shall 在执行前失败关闭或明确报告控制失败，不操作无法证明归属的进程。

## 4. 快照与受管回滚
用户故事：作为开发者，我希望撤销任务时不丢掉自己原有的未提交工作。

- 4.1 When 执行受管文件写入，the Yunyi shall 在修改前保存真实文件字节或不存在标记及必要元数据，包括未提交改动。
- 4.2 When 回滚无冲突的受管写入，the Yunyi shall 恢复任务开始前的真实内容或删除本任务新建文件，不以仓库 HEAD 替代快照。
- 4.3 If 当前文件已被外部修改、路径越界、链接重定向或快照损坏，the Yunyi shall 停止该回滚并返回冲突证据，不覆盖新内容。
- 4.4 When 使用声明的补偿动作，the Yunyi shall 应用与正向执行相同的权限、超时和日志规则，按逆序记录成功、失败或部分回滚。
- 4.5 The Yunyi shall 明确区分 snapshot、compensation、none 三类恢复能力，不对网络请求、注册表或未声明写入承诺自动还原。
- 4.6 If 快照落盘失败或超过配置的容量上限，the Yunyi shall 在写文件前停止步骤；用户主动清理前不得删除仍被检查点引用的快照。

## 5. 重启核对与恢复报告
用户故事：作为用户，我希望重启后看清已做什么，并决定未知结果如何处理。

- 5.1 When 恢复会话，the Yunyi shall 保留已完成步骤且从下一个确认未执行步骤继续，拒绝重跑已完成步骤。
- 5.2 If 上次所有者消失且存在 running 步骤，the Yunyi shall 将其转为 needs_reconciliation，展示最后检查点和文件差异，要求可验证的核对结果后才能继续。
- 5.3 When 生成恢复报告，the Yunyi shall 列出成功、失败、阻塞、未知、文件冲突和回滚情况，供用户或上游规划器评估。
- 5.4 When 应用恢复决策，the Yunyi shall 验证会话、报告版本和动作授权；过期或重复决策不得重复执行副作用。

## 边界与相邻期待
依赖基础规格的原子领取和会话隔离；集成规格负责网络事件、Harness 交接和云端建议。云建议不能替代本地审批，独占锁不能被描述为阻止所有外部编辑器写入。
