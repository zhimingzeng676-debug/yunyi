# 实施任务：离线执行与恢复

完整串行任务清单，独立审查通过，用户批准待定。前置：netpilot-foundation 4.2 通过。每项行为使用完整 agentic-tdd 与独立审查；依赖上游编号通过下文命名明确区分。

- [ ] 1. 执行控制基础
- [ ] 1.1 实现精确本地策略及审批绑定（约3小时）
  - 验证真实 exe、参数、目录、写入范围与 action/policy hash。
  - 拒绝 shell/解释器字符串和危险 Git 参数，审批过期或配置改变使许可失效。
  - 完成时模型/MCP 不能签发本地批准，未授权步骤可解释地 pending_approval。
  - _Boundary: CommandPolicy_
  - _Requirements: 1.1, 1.2, 1.3, 1.5_
- [ ] 1.2 实现工作区互斥和交接校验（约2小时）
  - 两个真实进程争用同一工作区锁，验证进程退出释放锁。
  - 区分 cooperative、仅暂停和无交接，后两者不自动获写权限。
  - 完成时未确认交接的 file_write 不产生文件变化。
  - _Boundary: WorkspaceLock_
  - _Requirements: 1.4_
- [ ] 1.3 实现 Windows 受管进程启动和输出收集（约3小时）
  - 挂起创建后加入 Job，再恢复运行；附加失败不得启动。
  - 子进程输出超过限长时仍被排空，不阻塞父进程。
  - 完成时 argv 边界保持，正常退出返回正确结果且无多余窗口。
  - _Boundary: ProcessJob_
  - _Requirements: 3.1, 3.3_
- [ ] 1.4 实现超时、取消与进程树清理（约2小时）
  - 使用生出孙进程的 fixture 验证超时与控制器崩溃清理。
  - 验证 PID 身份不匹配、权限错误和无法确认退出时的结果。
  - 完成时所有受管后代退出，无法确认副作用时返回需核对而非成功。
  - _Boundary: ProcessJob_
  - _Requirements: 3.2, 3.3_

- [ ] 2. 可恢复文件动作
- [ ] 2.1 实现路径边界、快照与受管写入（约3小时）
  - 覆盖普通脏文件、新文件、Unicode 路径、junction、硬链接、ADS 与越界。
  - 验证先落快照再写目标、expected_before 冲突、容量和磁盘失败。
  - 完成时任何拒绝路径均未改变目标，合法写入能证明前后字节。
  - _Boundary: SnapshotStore_
  - _Requirements: 4.1, 4.3, 4.6_
- [ ] 2.2 实现精确恢复、补偿及部分回滚（约3小时）
  - 已外部改动的文件返回冲突；恢复原有脏字节，不使用全仓还原。
  - 逆序补偿使用同一策略、进程管理及 operation_id，崩溃不盲重放。
  - 全程持工作区锁，锁内重验交接/审批/报告版本；内部失败回滚复用有效context防自锁；父子步骤通过上游Repository领取/提交。
  - 完成时成功、冲突、部分失败都有持久化回滚日志。
  - _Depends: 1.1, 1.2, 1.4, 2.1_
  - _Boundary: RollbackService_
  - _Requirements: 1.4, 4.2, 4.3, 4.4, 4.5, 5.4_

- [ ] 3. 串行执行器
- [ ] 3.1 实现依赖调度和检查点驱动循环（约3小时）
  - 使用真实 Repository 领取、保存前检查点、运行动作、原子落结果。
  - 覆盖失败依赖阻塞、未审批任务、空队列、多步骤顺序与存储失败。
  - 完成时合法 DAG 正确执行，每个实际步骤都有前后事实，未完成记录不丢失。
  - _Depends: 1.1, 1.2, 1.4, 2.1_
  - _Boundary: OfflineExecutor_
  - _Requirements: 2.1, 2.2, 2.3_
- [ ] 3.2 实现有限重试、恢复停止和失败回滚接线（约2小时）
  - 非幂等或未知结果不自动重试；幂等明确失败验证重试次数和退避。
  - 恢复/取消停止领取并有界收尾，失败时只执行已许可回滚。
  - 完成时停止信号后无新步骤启动，回滚结果与任务事实关联。
  - _Depends: 2.2, 3.1_
  - _Boundary: ExecutionIntegration_
  - _Requirements: 2.4, 2.5, 3.2, 4.4_

- [ ] 4. 重启与核对
- [ ] 4.1 实现恢复报告与版本化决策（约2小时）
  - 报告列出成功、失败、未知、冲突和回滚事实。
  - 校验当前 report_version、会话与本地审批，重复 operation 不产生新副作用。
  - 完成时仅用户或可验证证据能解除未知，云建议不能自动提升权限。
  - _Boundary: RecoveryService_
  - _Requirements: 5.1, 5.2, 5.3, 5.4_
- [ ] 4.2 完成执行器真实故障注入验收（约3小时）
  - 分别在动作前、写入后、后检查点前和补偿过程中终止受管 fixture。
  - 重启后验证已完成不重跑、未知不自动执行、脏内容不被丢弃。
  - 两会话竞争正向执行与回滚，验证全程互斥、无效交接不写、多步骤补偿中断逐项保留事实。
  - 完成时 ProcessJob/Repository/快照的综合证据通过，交付集成规格。
  - _Depends: 3.2, 4.1_
  - _Boundary: ExecutionIntegration_
  - _Requirements: 1.4, 2.2, 2.3, 3.2, 4.2, 4.3, 5.1, 5.2, 5.4_
